# Palette

Generated by `mise run manual:gen` from `modules/desktop/theme/palettes/{uqbar,zahir}.nix` — the palette is data there; every surface (shell, office, ghostty, GTK/Qt, btop, floorp, hyprlock, lazygit, bat, fzf, cava, tmux, Claude Code, Neovim) is rendered from it by `render.nix`. Nothing else on the machine carries a hex value.

Font: **ComicShannsMono Nerd Font** everywhere, 11pt base (low vision: sizes bias up, never down).

## The law

- **Body text is amber on black** (uqbar) — dark amber on cream in zahir. Cyan = keys, labels, code, links. Lilac = secondary text.
- **Amber field = the CURSOR** (where you are: focused workspace, active tab, list row) as inverse video. **Violet field = the SELECTION** (what you picked and left behind). The test: *if you look away, does it stay?*
- Green = live/occupied. Pink = agents, the operator, attention. Red = alarm. Ember = warning, one step before red.
- Every pair clears WCAG AAA (7:1 text, 3:1 bands) in BOTH palettes — `mise run theme:contrast` proves it.

- **A wallpaper per palette:** `wallpapers = [ "~/Pictures/Wallpapers/uqbar" ];` in `palettes/<name>.nix` (files or directories) makes the shell's photo backdrop draw from them while that palette is live; empty falls back to the shared wallpapers directory. `mise run home:switch` to apply.
