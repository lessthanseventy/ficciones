# Verbs

Every verb is `mise run <name>`; the same loop for the human and the agents (AGENTS.md). Generated by `mise run manual:gen` from `mise tasks ls --json` — a verb is defined in `tasks/<group>.toml`, never here.

39 verbs in 18 groups. The launcher lists them under `>`.

## cap

| verb | does |
|---|---|
| `cap:clean` | Sweep the captured run logs (.logs/) of the repo you call it from — they self-cap at CAP_KEEP (40), this clears them now |

## check

| verb | does |
|---|---|
| `check:agent-work` | the CLAUDE_CODE_SHELL_PREFIX wrapper runs a command intact, pinned to the E-cores |
| `check:cap-hook` | the hook that refuses cap piped into a filter reaches every verdict it should |
| `check:mods` | the Claude Code mods' own tests, in Claude's harness (bare bun cannot resolve claude-code/testing), their list of menard's verbs against menard's, and the review pane's copy of the diff reader against the changes pane's (a mod may import only its own files) |
| `check:names` | names-exist gate: every mise task a guide names must exist (grep, offline, fast) |
| `check:session` | the session command sets a session's goal and next, and briefs them |
| `check:session-state` | the Claude Code hook that keeps each session's record and arena's pane mark writes what it should |
| `check:shell` | the desktop shell's own gate (shell:check), where ags is installed |

## shot

| verb | does |
|---|---|
| `shot:layer` | desktop: grim ONE of the shell's layer surfaces on the focused monitor (arg: rail\|bar\|deck\|backdrop, or any namespace substring; default bar). The shell draws in LAYERS, not windows, so shot:window cannot see it and shot:monitor makes you crop by hand. |
| `shot:monitor` | desktop: grim the focused monitor to ~/Pictures/Screenshots, print the path |
| `shot:region` | desktop: grim an arbitrary rectangle in global compositor coords (arg: 'X,Y WxH', e.g. '1920,40 48x280') — the escape hatch when the thing you want is not a window or a layer |
| `shot:window` | desktop: grim one window (arg: class/title regex; none = focused) to ~/Pictures/Screenshots, print the path |

## —

| verb | does |
|---|---|
| `cap` | Run a command once, capture ALL output to a log, print exit + failures + tail — then read the log for more, never re-run (see AGENTS.md) |
| `check` | Everything green: the names gate, the cap hook, the session hook and command, the mods' tests, the desktop shell's gate, the manual's drift check, and the flake |
