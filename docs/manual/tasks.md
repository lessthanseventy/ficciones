# Verbs

Every verb is `mise run <name>`; the same loop for the human and the agents (AGENTS.md). Generated by `mise run manual:gen` from `mise tasks ls --json` — a verb is defined in `tasks/<group>.toml`, never here.

29 verbs in 15 groups. The launcher lists them under `>`.

## cap

| verb | does |
|---|---|
| `cap:clean` | Sweep all captured run logs (.logs/) — they self-cap at CAP_KEEP (40), this clears them now |

## check

| verb | does |
|---|---|
| `check:names` | names-exist gate: every mise task a guide names must exist (grep, offline, fast) |

## flake

| verb | does |
|---|---|
| `flake:bump` | machine: nix flake update — every input, Expert included (it builds from its own flake) |
| `flake:check` | machine: nix flake check + build both closures — the machine-level gate |

## home

| verb | does |
|---|---|
| `home:switch` | machine: apply the home-manager profile |

## hyprlock

| verb | does |
|---|---|
| `hyprlock:preview` | theme: photograph the generated hyprlock.conf in a nested Hyprland, per palette — hyprlock has no dry-run and a bad lock config is found while locked out |

## keyd

## manual

| verb | does |
|---|---|

## shell

| verb | does |
|---|---|
| `shell:check` | shell: the gate — ags bundle (syntax + imports + scss), tsc over our files, then the node tests; all hard-fail |
| `shell:dev` | shell: run the shell from source (Ctrl+C stops it); pkill -x gjs first — the dbus name is taken while the installed shell runs |
| `shell:logs` | shell: follow the astal-shell unit's journal |
| `shell:restart` | shell: restart the astal-shell user unit (VM / post-cutover) |
| `shell:test` | shell: the pure-logic tests (node --test, no gi): lib/*.test.mjs |

## shot

| verb | does |
|---|---|
| `shot:layer` | desktop: grim ONE of the shell's layer surfaces on the focused monitor (arg: rail\|bar\|deck\|backdrop, or any namespace substring; default bar). The shell draws in LAYERS, not windows, so shot:window cannot see it and shot:monitor makes you crop by hand. |
| `shot:monitor` | desktop: grim the focused monitor to ~/Pictures/Screenshots, print the path |
| `shot:region` | desktop: grim an arbitrary rectangle in global compositor coords (arg: 'X,Y WxH', e.g. '1920,40 48x280') — the escape hatch when the thing you want is not a window or a layer |
| `shot:window` | desktop: grim one window (arg: class/title regex; none = focused) to ~/Pictures/Screenshots, print the path |

## theme

| verb | does |
|---|---|
| `theme:contrast` | theme: check BOTH palettes against the WCAG floors in contrast.nix (same check as flake's palette-contrast, with the full table printed) |
| `theme:gen` | theme: rewrite the palette-generated files in the repo from palette.nix (checks.palette-sync fails the flake when they drift) |

## vm

| verb | does |
|---|---|
| `vm:build` | machine: build the NixOS VM runner from nixosConfigurations.vm |
| `vm:run` | machine: boot the VM (vm:build first); disk state lives in .dev/vm.qcow2 |
| `vm:ssh` | machine: ssh into the running VM as andrew (password andrew); pass a command to run it |

## watch

| verb | does |
|---|---|
| `watch:stop` | Stop ficciones file-watchers left running in the background (safe: never signals its own shell) |

## —

| verb | does |
|---|---|
| `cap` | Run a command once, capture ALL output to a log, print exit + failures + tail — then read the log for more, never re-run (see AGENTS.md) |
| `check` | Everything green: the names gate, the manual's drift check, and the flake |
| `watch` | Re-run a command on every file change, printing cap's signal — register in the background, edit, get pass/fail automatically (see AGENTS.md) |
